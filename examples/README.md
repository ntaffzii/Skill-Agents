# Examples

โฟลเดอร์นี้เก็บ config และ prompt ตัวอย่างสำหรับเริ่มใช้งานจริง

## Files

- `claude-desktop-config.json` - ตัวอย่าง MCP stdio config สำหรับ Claude Desktop
- `lm-studio-mcp-config.json` - ตัวอย่าง `mcp.json` สำหรับ LM Studio
- `local-llm-agent-prompt.md` - system/project prompt สำหรับ local LLM หรือ provider ที่ไม่มี skill loader
- `personal-daily-agent-prompt.md` - prompt สำหรับ daily planning ส่วนตัว
- `obsidian-notion-sync-prompt.md` - prompt สำหรับ Obsidian ↔ Notion แบบ draft-only
- `http-mcp-client-notes.md` - notes สำหรับ client ที่เชื่อม HTTP MCP server

## How To Use

แก้ path, token, repo name, และ vault path ให้ตรงเครื่องของคุณก่อนใช้งาน
