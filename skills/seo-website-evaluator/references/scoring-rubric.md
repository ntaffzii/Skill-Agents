# เกณฑ์และรูบริกการให้คะแนน SEO (Detailed Scoring Rubric)

เอกสารนี้กำหนดเกณฑ์การประเมินและการตัด/ให้คะแนน 0-10 อย่างเป็นรูปธรรมในแต่ละหมวด เพื่อให้ผลการตรวจสอบแม่นยำ มีหลักฐานรองรับ และเป็นมาตรฐานเดียวกันทุกครั้ง

---

## สเกลคะแนนมาตรฐาน (Universal 0-10 Scale)

- **9.0 – 10.0 (Industry Benchmark / Pristine)**: ยอดเยี่ยม สมบูรณ์แบบตามมาตรฐานสากล ไม่มีข้อผิดพลาดทางเทคนิค โครงสร้างและเนื้อหาเหนือกว่าคู่แข่ง
- **7.0 – 8.9 (Good / Minor Polish Needed)**: คุณภาพดี มีข้อบกพร่องเล็กน้อยที่ไม่กระทบโครงสร้างหลักหรืออันดับอย่างมีนัยสำคัญ
- **5.0 – 6.9 (Fair / Needs Improvement)**: ปานกลาง มีจุดบกพร่องหลายจุดที่ส่งผลต่อประสิทธิภาพการ crawl, index หรือ user experience
- **3.0 – 4.9 (Poor / Significant Gaps)**: คุณภาพต่ำ มีข้อผิดพลาดรุนแรงที่ขัดขวางการเติบโตของ organic traffic และ AI search inclusion
- **0.0 – 2.9 (Critical / Toxic Failure)**: วิกฤต มี Red Flags หรือข้อผิดพลาดร้ายแรง เช่น โดนบล็อก crawl, โดน de-index, สแปม, หรือ mixed content

---

## 1. Technical SEO & Crawlability (น้ำหนัก 20%)

| ระดับคะแนน | ลักษณะที่พบ |
|:---:|---|
| **9-10** | Robots.txt และ XML Sitemap สมบูรณ์ 100%, ไม่มี orphan page, HTTPS สมบูรณ์, Canonical ชัดเจน, โครงสร้าง Flat (ไม่เกิน 3 คลิก), Schema Markup (JSON-LD) ครบและ Valid ไม่มี error |
| **7-8** | มีปัญหาเล็กน้อย เช่น มี Redirect chain สั้นๆ (2 hops), Schema ขาดบาง property ที่ไม่ใช่ required, Sitemap ลืมอัปเดต URL ล่าสุดบางส่วน |
| **5-6** | มีปัญหาปานกลาง เช่น พบ Broken links (404) ภายในเว็บหลายจุด, มีหน้าสำคัญตกหล่นจาก Sitemap, Canonical ผิดพลาดในบางหมวดหมู่, ไม่มี Schema Markup เลย |
| **3-4** | มีปัญหาหนัก เช่น เกิด Index bloat จำนวนมาก (มีหน้า parameter/filter ซ้ำซ้อนนับพัน), โครงสร้างลึกเกิน 5 คลิก, Redirect loop |
| **0-2 (Red Flag)** | `noindex` ติดอยู่ในหน้าหลัก/หน้าสำคัญโดยไม่ได้ตั้งใจ, `robots.txt` สั่ง `Disallow: /` บล็อก crawler ทั้งหมด, ไม่มี HTTPS หรือ SSL พัง |

---

## 2. On-Page Optimization (น้ำหนัก 15%)

| ระดับคะแนน | ลักษณะที่พบ |
|:---:|---|
| **9-10** | Title tag (50-60 ตัวอักษร) มีคีย์เวิร์ดหลักขึ้นต้นและดึงดูดคลิก, Meta description (150-160 ตัวอักษร) มี CTA ชัดเจน, มี `<h1>` เดียวที่มีคุณภาพ, `<h2>`/`<h3>` จัดโครงสร้างเป็นระบบ, รูปภาพมี descriptive alt text และ WebP/AVIF ทุกรูป, URL สั้นกระชับ |
| **7-8** | Title หรือ Meta description ยาว/สั้นเกินไปเล็กน้อยในบางหน้า, มีรูปภาพ 1-2 รูปที่ขาด alt text, การใช้ Semantic keyword ยังไม่ครอบคลุม |
| **5-6** | ขาด Meta description ในหลายหน้า, ใช้ `<h1>` ซ้ำซ้อนหลายจุดในหน้าเดียว หรือข้ามลำดับหัวข้อ (เช่น ข้ามจาก H1 ไป H3), รูปภาพส่วนใหญ่ไม่มี alt text, URL มี parameter ยาวเหยียด |
| **3-4** | Title tag ตั้งชื่อ generic ซ้ำๆ เช่น "หน้าแรก", "Home", "Untitled", ไม่มีโครงสร้าง Headings ที่ถูกต้อง, มีแนวโน้มทำ Keyword stuffing |
| **0-2 (Red Flag)** | Title tag และ Meta description ซ้ำกันทั้งเว็บไซต์ (Site-wide identical duplicate), มีการซ่อนข้อความ (Hidden text) หรือยัดคีย์เวิร์ดผิดธรรมชาติ |

## 3. Content Quality & E-E-A-T (น้ำหนัก 25%)

| ระดับคะแนน | ลักษณะที่พบ |
|:---:|---|
| **9-10** | ตอบ Search Intent ได้ตรงเป้า 100%, เนื้อหาเจาะลึกและมี Original Value ที่หาจากที่อื่นไม่ได้, มี Experience Signals (รูปถ่ายจริง, การทดสอบจริง, ตัวเลขสถิติเฉพาะ), ระบุชื่อและประวัติผู้เขียนพร้อมความเชี่ยวชาญ (Author Bio), อ้างอิงแหล่งข้อมูลปฐมภูมิชัดเจน, มี Topical Authority เชื่อมโยงเป็น Content Cluster |
| **7-8** | เนื้อหาเขียนดี ครอบคลุมคำถามหลัก แต่ยังขาดข้อมูลเชิงลึกเฉพาะตัว (Original data) หรือข้อมูลประวัติผู้เขียนยังไม่สมบูรณ์ |
| **5-6** | เนื้อหาผิวเผิน (Thin content) เป็นการสรุปข้อมูลทั่วไปที่พบได้ตามอินเทอร์เน็ต ไม่มีมุมมองใหม่, ไม่มีข้อมูลผู้เขียน, วันที่อัปเดตไม่ชัดเจน |
| **3-4** | เนื้อหาบางมาก ไม่ตอบคำถามของผู้ค้นหา, ดูเหมือนเขียนขึ้นเพื่อหวังผล SEO เพียงอย่างเดียวโดยไม่มีคุณค่าต่อมนุษย์ |
| **0-2 (Red Flag)** | เนื้อหาลอกเลียนแบบ (Scraped / Duplicate content), เป็นขยะบทความจาก AI ล้วนๆ (Mass AI-spun) ที่ไม่มีการตรวจสอบความถูกต้อง หรือให้ข้อมูลอันตรายด้าน YMYL |

## 4. Off-Page Authority & Trust (น้ำหนัก 15%)

*(หมายเหตุ: หากไม่มีสิทธิ์เข้าถึงเครื่องมือ Backlink แบบเรียลไทม์ ให้ประเมินเชิงคุณภาพจาก Brand Presence / Mentions หากไม่สามารถประเมินได้ ให้บันทึกเป็น `N/A` แล้ว Re-normalize น้ำหนัก)*

| ระดับคะแนน | ลักษณะที่พบ |
|:---:|---|
| **9-10** | มีการกล่าวถึงแบรนด์ (Brand mentions) จากสื่อหรือแหล่งอ้างอิงชั้นนำในอุตสาหกรรมอย่างต่อเนื่อง, Referring Domains มีคุณภาพสูงและตรงสายงาน, Anchor text เป็นธรรมชาติ, ข้อมูล Google Business Profile (GBP) ยืนยันสมบูรณ์และมีรีวิวจริงที่น่าเชื่อถือ |
| **7-8** | มีแบรนด์เป็นที่รู้จักในวงการ มีการอ้างอิงจากเว็บภายนอกพอสมควร แต่ยังขาดลิงก์จากสื่อระดับสูง |
| **5-6** | แบรนด์ยังใหม่ มีการอ้างอิงจากภายนอกน้อยมาก, สัดส่วน Anchor text ยังไม่หลากหลาย |
| **3-4** | แทบไม่พบร่องรอยของแบรนด์บนโลกออนไลน์ หรือพบ Backlink จากเว็บคุณภาพต่ำ/ฟอรัมสแปม |
| **0-2 (Red Flag)** | มีสัญญาณการซื้อขายลิงก์แบบผิดกฎ (Spam Link Schemes), โดน Toxic Backlink โจมตีหนักจนอาจเสี่ยงโดน Google Manual Action |

## 5. Page Experience & Core Web Vitals (น้ำหนัก 15%)

| ระดับคะแนน | เกณฑ์ Core Web Vitals & UX |
|:---:|---|
| **9-10** | ผ่านเกณฑ์ Good ของ Core Web Vitals ทั้ง 3 ตัว:<br>• **LCP $\le 2.5\text{s}$**<br>• **INP $\le 200\text{ms}$**<br>• **CLS $\le 0.1$**<br>Mobile Responsive สมบูรณ์แบบ, ไม่มี Pop-up ขัดขวางเนื้อหา, เมนูใช้งานง่าย, ปุ่มกดมีขนาดตามมาตรฐาน ($\ge 44 \times 44\text{px}$) |
| **7-8** | ผ่าน 2 ใน 3 ตัวของ Core Web Vitals (เช่น LCP อยู่ช่วง 2.5-3.5s แต่ INP และ CLS ดี), Mobile UI ใช้งานได้ดี |
| **5-6** | Core Web Vitals อยู่ในเกณฑ์ Needs Improvement ทั้งหมด (LCP 3-4s, INP 200-500ms, CLS 0.1-0.25), มี Pop-up กวนใจตอนเข้าหน้าเว็บ |
| **3-4** | ตกเกณฑ์ Poor หลายตัว (LCP > 4s, INP > 500ms, CLS > 0.25), เว็บหน่วงมาก, เกิด Layout Shift บ่อยครั้ง |
| **0-2 (Red Flag)** | เว็บไม่รองรับ Mobile (ไม่มี viewport meta tag), หน้าเว็บล้นจอแนวนอน (Horizontal scroll), องค์ประกอบ UI ทับซ้อนจนกดใช้งานไม่ได้ |

## 6. AI Search Readiness — GEO / AEO (น้ำหนัก 10%)

| ระดับคะแนน | ลักษณะความพร้อมสำหรับ Generative Engine |
|:---:|---|
| **9-10** | มี Direct Answer ที่ตอบตรงประเด็นใน 1-2 ประโยคแรกของแต่ละส่วน, มีโครงสร้าง Q&A ชัดเจน, มี Schema FAQPage/HowTo ที่ตรงกับหน้าเว็บจริง, อนุญาต AI Bot ใน `robots.txt`, มีไฟล์ `llms.txt` และ `llms-full.txt` ที่จัดรูปแบบตามมาตรฐาน Markdown สะอาด |
| **7-8** | เนื้อหามีโครงสร้างตอบคำถามที่ดีและดึงข้อความง่าย (Extractable) มี Schema Markup บางส่วน แต่ยังไม่มีไฟล์ `llms.txt` |
| **5-6** | เนื้อหาเป็นพารากราฟขนาดยาวแบบดั้งเดิม (Wall of text) ไม่มี bullet หรือการสรุปใจความสำคัญที่ AI จะนำไป quote ได้ง่าย, ขาด FAQ schema |
| **3-4** | โครงสร้างเนื้อหาซับซ้อน ใช้ภาษาคลุมเครือ ไม่ระบุคำจำกัดความที่ชัดเจน, ซ่อนข้อมูลไว้หลัง JavaScript ที่ AI crawler บางตัวเข้าไม่ถึง |
| **0-2 (Red Flag)** | เนื้อหาเป็นภาพกราฟิกล้วนๆ ไม่มีตัวอักษร HTML, โครงสร้างหน้าเว็บพังเมื่อปิดการทำงานของ CSS/JS |
