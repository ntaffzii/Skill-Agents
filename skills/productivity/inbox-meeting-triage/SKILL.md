# Inbox Meeting Triage

Use this skill to turn communication noise into a small set of decisions and actions.

## Workflow

1. Gather supplied or configured sources.
   - Calendar events for time commitments.
   - Email messages for inbox actions.
   - Slack/Discord messages for chat actions.
   - Notion/Obsidian/memory for context.

2. Classify each item.
   - Reply
   - Schedule
   - Decide
   - Delegate
   - Read later
   - Turn into issue/task
   - Archive/no action

3. Draft outputs.
   - Meeting prep note.
   - Email/chat replies.
   - Issue/task drafts.
   - Obsidian-ready daily note section.

4. Verify privacy.
   - Do not send replies automatically.
   - Do not create issues automatically.
   - Do not expose private message content in public-facing summaries.

## Output Shape

Use compact sections:

- Calendar
- Inbox
- Chat
- Actions
- Draft Replies
- Issues/Tasks
- Notes To Save
