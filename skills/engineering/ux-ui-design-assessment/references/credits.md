# Credits And Inspiration

`ux-ui-design-assessment` is an original Skill-Agents synthesis created for this repository. It is **not** an official skill from UI Skills and is **not** a verbatim copy of any upstream skill. Specific techniques were adapted from public skills; see [external-techniques.md](external-techniques.md) for exactly what was drawn from each and how it was changed.

## Directory

- [UI Skills](https://www.ui-skills.com/skills/) by Interface Office provided the discovery directory and taxonomy across accessibility, motion, systems, visual design, interaction, performance, craft, taste, frameworks, and testing.

## Primary Inspirations

- [Design Lab](https://www.ui-skills.com/skills/0xdesign/design-lab) by 0xdesign inspired the Design-mode loop: interview -> brief -> distinct variants -> feedback -> finalize, the open-ended question discipline, the variant axes, and the quantitative accessibility thresholds.
- [UI/UX Pro Max](https://www.ui-skills.com/skills/nextlevelbuilder/ui-ux-pro-max) by nextlevelbuilder inspired the priority-tiered guideline structure, the concrete numeric rules, and the anti-pattern list.
- [Improve UI](https://www.ui-skills.com/skills/ibelick/improve-ui) by Ibelick inspired the evidence-based audit method: the three-part proof gate, falsification, and the "no supported findings" honesty.
- [Rams](https://www.ui-skills.com/skills/rams/rams) inspired the quantitative, checkable quality bars for spacing, typography, and contrast.
- [Web Design Guidelines](https://www.ui-skills.com/skills/antfu/web-design-guidelines) by Antfu inspired the accessibility-and-UX compliance checklist mindset.

## Body Of Knowledge

The ten-topic UX/UI methodology embedded in this skill (UX/UI foundations, Design Thinking, user research, information architecture, wireframe/mockup/prototype, visual hierarchy, color and typography, responsive design, moodboard, usability testing) reflects standard, widely taught UX/UI practice rather than any single upstream skill.

## Adaptation For Skill-Agents

The following are specific to this repository and are not claims about upstream skills:

- The two-mode (Audit / Design) workflow oriented around producing a documentation file.
- The ten-dimension audit rubric and its mapping to the body of knowledge.
- Integration with the `ui-design-engineering` companion skill (this skill assesses and documents; that skill implements fixes).
- The report and design-doc output templates.
