# เรซูเม่ / Resume — Bilingual Template

> Synthetic example. ปรับ field ที่มีเครื่องหมาย [optional] ตามความเหมาะสมของบริษัทเป้าหมาย — ดู SKILL.md ส่วน "DOB/photo/religion" ก่อนตัดสินใจใส่หรือไม่ใส่.

```
[รูปถ่าย — optional, formal headshot ถ้าใส่]

ชื่อ-นามสกุล / Full Name: [ชื่อ] [นามสกุล]
ตำแหน่งที่สนใจ / Applying for: [ตำแหน่งงาน]
เบอร์โทร / Phone: [เบอร์]
อีเมล / Email: [email]
LinkedIn: [url]

ข้อมูลส่วนตัว / Personal Info  [ทั้งหมดนี้ optional — ดู Known limitations]
วันเกิด / DOB: [optional]
สัญชาติ / Nationality: [optional]
สถานภาพ / Marital status: [optional]
ศาสนา / Religion: [optional — ใส่เฉพาะกรณีที่บริษัทเป้าหมายคาดหวังชัดเจน]
ภาวะทางทหาร (เฉพาะเพศชาย) / Military status: [ผ่านการเกณฑ์ทหารแล้ว / ได้รับการยกเว้น — optional]

ประวัติการศึกษา / Education
[ปี] [สถาบัน] — [วุฒิการศึกษา/สาขา]

ประสบการณ์ทำงาน / Work Experience
[ปี-ปี] [ตำแหน่ง] ที่ [บริษัท]
- [ผลงาน/ความรับผิดชอบสำคัญ — เน้นผลลัพธ์เชิงตัวเลขถ้ามี]

ทักษะ / Skills
[ทักษะที่เกี่ยวข้องกับตำแหน่ง]

ผลงาน / เกียรติประวัติ / Portfolio, Awards  [optional]
[รายการ]
```

---

*Template นี้เป็นโครงสร้างอ้างอิงเท่านั้น ปรับตามอุตสาหกรรมและช่องทางที่ยื่นสมัคร (JobsDB/JobThai มักคาดหวัง field แบบไทยดั้งเดิมมากกว่า LinkedIn).*
