# หนังสือราชการ (Official Letter) — Template

> Synthetic example. Structure follows the ระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ (regulation on official correspondence) — verify the current edition before using on a real document.

```
ที่ [เลขที่หนังสือ]                                    [ตราครุฑ/หัวกระดาษหน่วยงาน]
                                                        [ชื่อส่วนราชการเจ้าของหนังสือ]

                                          วันที่ [16] [พฤษภาคม] [2568]

เรื่อง  [หัวข้อเรื่องสั้น กระชับ ระบุใจความสำคัญ]

เรียน  [ตำแหน่งผู้รับ เช่น "ผู้อำนวยการโรงเรียน..." หรือ "อธิบดีกรม..."]

อ้างถึง  [ถ้ามีหนังสือที่เคยติดต่อมาก่อน ระบุที่ วันที่ เรื่อง — ถ้าไม่มีให้ลบบรรทัดนี้]

สิ่งที่ส่งมาด้วย  [เอกสารแนบ ถ้ามี — ถ้าไม่มีให้ลบบรรทัดนี้]

     [ย่อหน้าที่ 1: ความเป็นมา/เหตุผลที่มีหนังสือฉบับนี้]

     [ย่อหน้าที่ 2: ใจความสำคัญ/สิ่งที่ต้องการให้ผู้รับดำเนินการ]

     [ย่อหน้าที่ 3 (ถ้ามี): สรุปหรือขอความอนุเคราะห์]

                              ขอแสดงความนับถือ


                              [ลงชื่อ]
                            ([ชื่อ-นามสกุลตัวบรรจง])
                              [ตำแหน่ง]

[ส่วนราชการเจ้าของเรื่อง]
โทร. [เบอร์โทร]
โทรสาร [เบอร์แฟกซ์ ถ้ามี]
```

**หมายเหตุการใช้คำขึ้นต้น (เรียน/กราบเรียน):**
- `เรียน` — ใช้เป็นค่าเริ่มต้นสำหรับหนังสือราชการทั่วไปถึงบุคคล/หน่วยงานส่วนใหญ่
- `กราบเรียน` — สงวนไว้สำหรับผู้รับที่มีตำแหน่งสูงมาก (เช่น นายกรัฐมนตรี ประธานองคมนตรี ประธานศาลฎีกา) หรือกรณีที่ระเบียบ/ธรรมเนียมของหน่วยงานกำหนดไว้ชัดเจน — อย่าใช้ `เรียน` เมื่อบริบทต้องการ `กราบเรียน`
- `นมัสการ` — ใช้เมื่อผู้รับเป็นพระภิกษุสงฆ์

*เอกสารตัวอย่างนี้เป็น draft สำหรับอ้างอิงเท่านั้น ไม่ใช่คำแนะนำทางกฎหมาย โปรดตรวจสอบระเบียบงานสารบรรณฉบับล่าสุดและธรรมเนียมของหน่วยงานก่อนใช้จริง.*
